## 📖 Case Study Documentation
The formal 37-page Software Engineering Case Study Report following the prescribed CBIT format is located in the repository:

- 📑 **Printable PDF**: [`docs/FoodPulse_SE_Case_Study_Report.pdf`](./docs/FoodPulse_SE_Case_Study_Report.pdf)

### Report Structure
1. **Introduction**: Problem Statement, Objectives, Applications, Motivation, CO-PO-PSO Matrix compliance.
2. **Literature Survey**: Existing delivery platforms, Process models review, BaaS & Realtime comparison, Gap analysis.
3. **Software Requirements Specification (IEEE 830)**: Functional & non-functional requirements, user stories, software/hardware requirements.
4. **Proposed Methodology & System Design**: Agile Scrum sprint plan, Function Points (272 FP), Basic COCOMO estimation, Risk register, 3-Tier architecture, Use case, DFD (Level 0 & 1), Class, Sequence, State, and ER diagrams.
5. **System Implementation**: React 19, TypeScript, Tailwind CSS, Supabase PostgreSQL, Row Level Security, Realtime tracking, and in-app **SE Studio**.
6. **Testing & Results**: Black-box (11 cases), White-box (5 cases), Functional UI (9 cases), McCall & FURPS quality models, and screenshots.
7. **Conclusion, Limitations & Future Scope**: Real-world evaluation and commercial roadmap.

## 🛠️ Technology Stack
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Backend / Database**: Supabase (PostgreSQL, Supabase Auth, Row Level Security, Realtime WebSockets)
- **Deployment**: Vercel Edge Network with TLS 1.3 SSL
